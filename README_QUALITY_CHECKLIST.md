# DeepMap — README Quality Checklist

## Beginner clarity
- [ ] First paragraph explains the problem and benefit without unexplained jargon.
- [ ] A concrete example shows what a user can do.
- [ ] Setup commands include prerequisites and expected output.
- [ ] Sample, mock and synthetic data are labelled clearly.

## Engineering and research depth
- [ ] Inputs, outputs, architecture and dependencies are described.
- [ ] Data sources, schema, assumptions and limitations are documented.
- [ ] Tests, benchmarks and reproduction commands are linked.
- [ ] Complexity, uncertainty and failure modes are discussed where relevant.

## Collaboration
- [ ] Activity log, feature plan and company-fit guide are linked.
- [ ] Contribution instructions explain branches, tests and PR evidence.
- [ ] Every completion claim is backed by code or a reproducible result.
